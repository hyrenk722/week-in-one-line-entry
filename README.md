One line summing up my week on make.fun, 25 November 2026: twenty-five
contests entered, zero wins, and the family dog Bu — hero of the TX6
homepage since 24 November — now has a better homepage than I do.

> Twenty-five contests, zero wins, one dog named Bu who now has a better homepage than I do.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program writes the 90-character line to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt`) with no network access; two runs write
identical bytes.
